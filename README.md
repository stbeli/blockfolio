# Blockfolio

Blockfolio is a WordPress block theme for a personal portfolio and resume
(CV). It uses Full Site Editing, custom Gutenberg blocks, and templates for
displaying professional experience in a Google Docs-like document layout.

## Requirements

- WordPress 6.7 or later
- PHP 8.0 or later
- Node.js and npm (only for developing or building custom blocks)

## Installation

1. Copy the theme directory to `wp-content/themes/blockfolio`.
2. Install the development dependencies to work with the block source code:

   ```bash
   cd wp-content/themes/blockfolio
   npm ci
   npm run build
   ```

3. In the WordPress administration area, open **Appearance > Themes** and
   activate **Blockfolio**.

The `build/` directory contains the compiled JavaScript and CSS files required
by custom blocks. It is generated by `npm run build` and must be present in
the production installation.

## Development

Start the watch process while developing blocks:

```bash
npm run start
```

Other available commands:

| Command | Purpose |
| --- | --- |
| `npm run build` | Creates optimized files in the `build/` directory. |
| `npm run start` | Watches for changes in `src/` and rebuilds blocks automatically. |
| `npm run format` | Formats supported source files. |
| `npm run lint:js` | Lints the JavaScript code. |
| `npm run packages-update` | Updates packages used by `@wordpress/scripts`. |

Do not edit files in `build/` manually. Update the source files in `src/`,
then rebuild the blocks.

## Custom Blocks

The theme registers every block whose `block.json` file is located in the
`build/` directory.

### Table of Contents

A dynamic block that automatically builds a table of contents with anchor links
from the current page's headings. It supports standard WordPress Heading
blocks, along with section and position titles from the work-experience blocks.

### Work Experience

A container block for a work-experience section. Add one **Company** block for
each position or company.

### Company

A work-experience item with a company name, description, URL, role, employment
period, icon, and list of responsibilities. It can indicate an ongoing role in
place of an end date.

## Templates and Patterns

- Page templates: front page, single post, and index.
- Template parts: header, footer, sidebar, and portfolio.
- The **Intro** pattern for a name, role, contact details, image, and links.
- A hidden pattern for an automatically generated sidebar table of contents.
- The **No Border** button style for borderless buttons.

After activating the theme, you can edit its content and layout in
**Appearance > Editor**.

## Project Structure

```text
blockfolio/
├── assets/       # Fonts, icons, and other static assets
├── build/        # Generated custom-block assets
├── parts/        # WordPress template parts
├── patterns/     # Gutenberg editor patterns
├── src/          # Custom-block source code
├── styles/       # Block styles and variations
├── templates/    # Page templates
├── functions.php # Block registration and theme functionality
├── style.css     # Theme metadata and base styles
└── theme.json    # Global settings, palette, and typography
```
